# aircraft-tracker

## Описание:
Проект для получения, анализа и хранения информации о самолётах.

Приложение получает данные о воздушных судах через API OpenSky Network, 
позволяет сравнивать самолёты по скорости и высоте, а также сохранять, 
загружать и удалять данные в JSON-файле.


## Установка:

1. Клонируйте репозиторий:
git clone https://github.com/Master2077/aircraft-tracker

2. Установка зависимостей:
poetry intsall

## Тестирование:
В проекте используется pytest для модульного тестирования

### Использование:
1. Введите название страны, над которой нужно получить информацию о самолётах.
2. Выберите необходимое действие:

   1. Получить топ `N` самолётов по высоте полёта.
   2. Получить топ `N` самолётов по горизонтальной скорости.
   3. Получить список самолётов по стране регистрации.
3. Введите то что вас просят в вашем выбранном действии
